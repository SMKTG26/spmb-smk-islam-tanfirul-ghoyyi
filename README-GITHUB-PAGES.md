# SPMB SMK Islam Tanfirul Ghoyyi — GitHub Pages

## Upload ke GitHub
1. Buat repository baru di GitHub, misalnya `spmb-smk-islam-tanfirul-ghoyyi`.
2. Upload **seluruh isi folder ini** ke repository (bukan folder induknya).
3. Pastikan branch utama bernama `main`.
4. Buka **Settings → Pages** dan pilih **GitHub Actions** sebagai Source.
5. Push/commit perubahan. Workflow `.github/workflows/deploy.yml` akan membangun dan menerbitkan website.

URL biasanya:
`https://USERNAME.github.io/spmb-smk-islam-tanfirul-ghoyyi/`

## Catatan
- Website menggunakan Vite + React.
- Build dijalankan otomatis oleh GitHub Actions.
- File gambar dan aset sudah berada di dalam proyek.
